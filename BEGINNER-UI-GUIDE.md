# How to ask AI for better website and app design

You know what you want your website to feel like. Explaining why the current version feels wrong can be harder.

Start with one screen and one problem. This short guide gives you a repeatable way to describe it, review the response, and decide what to ask next.

## 1. Describe the job of the screen

Write down:
- Who is using it?
- What should they do next?
- What is making that difficult?
- What needs to stay the same?

“Help a first-time visitor understand my service and book a call” gives more direction than “make this modern.”

## 2. Give the AI something specific to review

Share a screenshot or relevant code you are allowed to share. Remove private information first.

Here is an original starter exercise for this guide:

> Review this [website/app screen] for [audience]. The main task is [task]. I’m worried about [specific problem]. Identify the three most useful improvements to layout, wording, or visual hierarchy. Explain each in beginner-friendly language. Keep [constraints] unchanged. Ask for missing context instead of guessing.

Customize everything in brackets. A screenshot review cannot establish whether keyboard navigation, screen-reader behavior, or interactions actually work; test those in the running interface.

## 3. Choose one change

You do not have to accept every suggestion. Pick the one that best supports the screen’s main task.

> Let’s focus on [chosen improvement]. Suggest a small change I can try first. Explain what I should look for when comparing it with the original.

## 4. Follow up when it still feels off

Replace “try again” with the part that missed:

> The result makes [thing] clearer, but [remaining problem] is still getting in the way. Keep [what worked] and revise [what needs work]. Explain the trade-off.

## 5. Review the result

- Can someone tell what the screen is for?
- Is the next action easy to find?
- Is the wording understandable without extra explanation?
- Does the layout still work on a small screen?
- Have you checked text contrast, keyboard focus, and real interactions?
- Did the change improve the original problem?

AI suggestions are starting points. Check the actual result and, where possible, ask someone from your intended audience to try it.
